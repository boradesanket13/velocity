# Frontend

React + Vite + Tailwind + shadcn/ui dashboard for creating deployments.

```bash
cp .env.example .env    
npm install
npm run dev       
npm run build           
```

The user pastes an **access key** (one of the tokens configured in the API's `API_KEYS`).
It is kept in `sessionStorage` only. See the root README for the full platform setup.
